# CS422 assignments

> Historical coursework portfolio from SMU CS422: Reasoning, Planning and Learning under Uncertainty. These submissions are not actively maintained.

## Overview

The repository contains completed assignments covering Bayesian networks, Markov decision processes, multi-armed bandits, deep reinforcement learning, policy gradients, and behavioural cloning.

University-issued question papers are intentionally not included. The answer PDFs, notebooks, and trained weight files are retained as portfolio evidence.

## Repository map

| Path | Topics |
| --- | --- |
| [`Assignment 1/`](./Assignment%201) | Bayesian-network inference and MDP solutions using value iteration and linear programming. |
| [`Assignment 2/`](./Assignment%202) | Multi-armed bandits, DQN and REINFORCE for Pong, and behavioural cloning for CartPole. |

Keep notebooks and weight directories together: the saved checkpoints are historical outputs associated with the adjacent notebooks.

## Historical environment

Major dependencies include NumPy, Matplotlib, pgmpy, PuLP, TensorFlow, TensorFlow Probability, Gymnasium, Stable-Baselines3, and the `imitation` package. The Atari notebook also installed Gymnasium Atari extras and ROM-license support inside the notebook.

The notebooks record several locally named Python environments rather than one pinned environment. Current compatibility, package versions, and Atari setup have not been verified.
